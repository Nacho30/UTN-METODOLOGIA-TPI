# 01 — Visión y objetivos

## Visión
Que Recepción de un consultorio odontológico pequeño pueda dar turnos **sin dobles reservas** y ver la agenda del día en segundos.

## Objetivos de esta entrega (TPI)
1. **C-01:** registrar turnos rechazando choques de profesional y de box (D-01).
2. **C-02:** consultar la agenda de un día por API y por pantalla web (D-02).
3. Demostrar el flujo **Discovery → KB → Roadmap → OpenSpec → pruebas** con un agente de IA y una skill propia.

## Indicadores de éxito
- 0 turnos superpuestos para el mismo profesional o box, incluso con altas simultáneas.
- Todas las reglas cubiertas por pruebas automáticas.
- El proyecto se levanta siguiendo sólo el README.

## Límites
Sólo datos ficticios, API local, sin integraciones externas ni historia clínica.
